# Snooze Button Roast

A one-line roast of an alarm clock that rings at 6 AM on a Saturday — set
"just in case" by a past self, at full volume, for a night-shift nurse whose
baby had just fallen asleep. The punchline lands in the last three words.

## How to run

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` (creating the directory if
needed). Python standard library only; no dependencies.
